THE IDEA

THE NEXT THING IS ALWAYS WAITING.

Social platforms can continuously present new content, notifications and interactions. The important point for this project is not that every use of social media is automatically harmful, but that these systems can encourage repeated engagement.

The visitor is invited to notice the difference between intentionally choosing to use a platform and automatically continuing to use it.
